# Responding to Editors and Referees

> When to read: writing a response letter; categorising reviewer comments;
> handling "revise and resubmit". Source: Cargill & O'Connor (2009), Ch. 14.

## Four rules of thumb

1. It is rare that the referee is completely right and the author completely
   wrong — or vice versa.
2. The object is to **accommodate** the referee's comments without
   compromising the paper's message (the story).
3. Always show the editor you are doing everything possible to **improve** the
   manuscript.
4. Rejection and criticism do **not** automatically mean the science is bad or
   the writing poor — consider other journals, additional work, or rewriting.

## Seven categories of reviewer comment

Sort each comment into one of these categories. The category dictates the
response.

| Category | What it means |
|----------|---------------|
| 1 | The **aims** of the study are not clear. |
| 2 | The **theoretical premise** / "school of thought" is challenged. |
| 3 | The **experimental design or analysis methods** are challenged. |
| 4 | You are asked to **supply additional data**. |
| 5 | You are asked to **remove** information or discussion. |
| 6 | The **conclusions** are considered incorrect, weak, or too strong. |
| 7 | **Unspecific negative** comments ("poorly designed", "badly organised", "English is poor"). |

If a comment doesn't fit, decide what it is **really** about before deciding
how to respond.

## Response strategies by category (Table 14.2)

| Comment type | Author response | Where in manuscript |
|--------------|-----------------|---------------------|
| **1 Aims unclear** | Rewrite the aims clearly | Introduction (Stage 4) |
| | Ensure aims are consistent with the experimental design | Cross-check Intro Stage 4 ↔ Methods |
| | Ensure the Discussion refers back to the aims | Cross-check Discussion ↔ Intro Stage 4 |
| **2 Theory challenged** | Show the diversity of theories (cite literature); demonstrate you are testing one | Introduction Stages 2 & 4; maybe Discussion |
| | If challenging accepted wisdom: explain the theory, cite work that explores it, use structure (headings, topic sentences) to stage the logic | Introduction Stage 2; maybe Discussion |
| | Include constraints (when results may not apply) | Discussion |
| **3 Design/methods challenged** | Defend the design on its merits | In the response letter |
| | Cite previously published examples using the design/methods | Methods; also response letter |
| | Include additional information on design/analysis if available | Methods; maybe Discussion |
| **4 Asked for more data** | Supply it if you can | Results (maybe other sections) |
| | If you cannot and only minor changes are needed, make the case to the editor | Response letter |
| | If major changes would be needed, consider rewriting so the extra data is unnecessary | All sections |
| **5 Asked to remove** | Remove if it doesn't change the story | Where indicated (usually Intro/Discussion) |
| | If cuts would alter the story, weigh positives in editor's letter and make your case for retaining | Response letter |
| **6 Conclusions wrong/weak/strong** | Tie the Discussion to the aims at the start of the paper | Discussion ↔ Intro Stage 4 |
| | Reassess cited literature; cite supporting work; make the case to the editor if needed | Discussion + response letter |
| | Ensure every statement is justified and the language strength is appropriate | Discussion |
| | Include constraints | Discussion |
| **7 Unspecific negative** | Show the comments to a colleague; discuss | All relevant sections |
| | Restate or rewrite the section(s); note each change to the editor | Response letter |
| | Point out all the work done to improve — build a body of positives | Response letter |
| | Seek language/editorial assistance if writing or grammar was criticised | Relevant sections |

## The two most powerful tools

- **Citing the published literature.** Published work is already vetted;
  compare/contrast findings to support your argument.
- **Improving manuscript structure.** Use the sectioning, topic-sentence, and
  flow techniques in `academic-writing`.

## Writing the response letter

Respond **quickly**, whether the decision was minor-changes or revise-and-
resubmit. Use the letter to:

- Thank the editor; confirm you've made all suggested changes.
- List the main changes individually, referring to referees' reports.
- Note you've also corrected minor errors (e.g., English).
- Point out supportive comments by referees and any disagreements (side with
  the referee you think is right; try to get the editor on side).
- Defend your work where a referee is factually wrong — another chance to cite
  key published papers.
- State you believe the paper is now acceptable.

**Copy all reviewer comments into the letter** (distinguish them typographically
— e.g., bold — from your responses) and respond to each one. Re-check the
manuscript conforms to the Instructions to Contributors.

### Example response excerpt (Cargill Fig. 14.2)

> **Response to comments by Referee #1**
>
> 1. **Survey site markers in Fig 2 are too small.**
>    Survey site markers have been increased in size.
>
> 2. **How were aₙ(x) and bₙ(x) computed? If they were computed empirically
>    this should be stated in the text.**
>    Yes, aₙ(x) and bₙ(x) were computed empirically. The relevant section now
>    reads: "The quantities aₙ(x) and bₙ(x) were derived empirically, by
>    calculating…"
>
> 3. **The notation in the equations is very complex and as this paper may be
>    of interest to practitioners it would be better to reduce the use of
>    symbols in Equations (1)–(7).**
>    The notation of Equations (1)–(7) comes from another paper, so must be
>    left as is. However, we have eliminated the use of β in reference to
>    statistical power, and just used the word 'power' instead.

Note: each response is specific, shows the change made (or gives a reasoned
pushback), and stays polite.
