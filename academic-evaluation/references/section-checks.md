# Section Checks — What to Verify Per Section

> When to read: reviewing a specific section of a draft. Source: Cargill &
> O'Connor (2009), Ch. 5–11.

Use the checklist for the section the user asked you to check. Each item maps
to a referee criterion (numbered in parentheses, from `referee-criteria.md`).

## Title (criterion 11)

- [ ] Title reflects the paper's actual content.
- [ ] Significant keywords appear near the beginning.
- [ ] Within the journal's word/character limit.
- [ ] Not ambiguous (noun-noun strings ≤ 3 words).
- [ ] Form chosen deliberately (noun phrase / statement / question) — not a
      vague "The effects of…" opener.

## Abstract (criteria 11, 19, 20)

- [ ] Contains all required elements (B/P/M/R/C or the journal's prescribed
      format).
- [ ] Highlights the key results and their significance.
- [ ] Within the word limit.
- [ ] No references, no figures/tables, no judgemental statements
      ("surprisingly…", "we believe…").
- [ ] Every method mentioned has a corresponding result.

## Introduction (criteria 1, 2, 3, 4)

- [ ] Stage 1 establishes importance and narrows (country → province → city).
- [ ] Stage 2 locates the work in recent international literature.
- [ ] Stage 3 explicitly signals a gap (signal words: *however*, *remains a
      challenge*, *rarely*, *not well understood*).
- [ ] Stage 4 states the aim/hypothesis clearly, using consistent wording with
      Methods, Results, and Discussion.
- [ ] All title keywords appear by the end of Stage 4.
- [ ] Citations support claims; no plagiarism (every borrowed idea cited in
      the sentence where it appears).
- [ ] Appropriate tense (present for general truths; past/present perfect for
      prior work; past for the aim).

## Methods (criterion 5, 8)

- [ ] Enough detail for reproducibility and credibility.
- [ ] Subheadings match Results subheadings (Strategy 1).
- [ ] Paragraphs open by linking to the aims (Strategy 2).
- [ ] Novel methods described in full; published methods cited.
- [ ] Primary and secondary endpoints stated.
- [ ] Equipment/datasets sourced (manufacturer or repository).
- [ ] Statistical methods, software, sample-size justification, pre-specified
      subgroups included.
- [ ] No top-heavy sentences (subject + verb within first 7–9 words).
- [ ] Tense: past (passive or active).

## Results (criteria 5, 8, 9, 10)

- [ ] Reports what was observed — **no commentary** ("surprisingly…").
- [ ] Order matches Methods (or Discussion).
- [ ] Same subheadings as Methods.
- [ ] Each figure/table stands alone (title + legend with all 5 parts).
- [ ] No data duplicated between text and illustrations.
- [ ] All figures/tables necessary (could any be combined or deleted?).
- [ ] Tense: past for the study; present for the document/always-true.
- [ ] Highlights only the most important findings — does not restate every
      number from a table.

## Discussion (criterion 6)

- [ ] Opens by referencing the original aim/hypothesis.
- [ ] Restates the most important findings in order of significance.
- [ ] Compares findings with literature; offers explanations for differences.
- [ ] Claim strength matches evidence (`demonstrate`/`indicate`/`appears`/
      `suggests` chosen deliberately).
- [ ] States limitations that restrict generalisation.
- [ ] States implications and future directions.
- [ ] Diplomatic when disagreeing with prior work — reformulates rather than
      attacks.
- [ ] Connects back to the Introduction's "country" (broad significance).

## References (criterion 12)

- [ ] Every in-text citation has a list entry.
- [ ] Every list entry is cited at least once in text.
- [ ] Style (punctuation, italics, capitalisation, abbreviation) matches the
      journal exactly.
- [ ] References up to date (key recent work included).
- [ ] No secondary citations presented as primary (cite the original, not the
      intermediate).

## Figures and Tables (criteria 8, 9, 10)

- [ ] Each has a story-telling (not merely descriptive) title.
- [ ] Legend contains all five parts: title, what's shown, additional
      explanation, units/statistics, symbols/notation.
- [ ] Rows/columns sorted to highlight the main result.
- [ ] Numbers rounded to appropriate precision (no false accuracy).
- [ ] Consistent symbols and colours across figures.
- [ ] Figure proportions ~3:2; boxed if sparse, unboxed if dense.
- [ ] Shrinks to journal column width and stays legible.
